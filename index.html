If something goes wrong

  • Get to Windows: Ctrl+Shift+F12 + staff or maintenance PIN → Exit to Windows, then sign in as Administrator.
  • Back to cafe mode: restart the PC. After the recovery USB, run Cafe Mode ON on the Administrator desktop first.
  • If the PIN box won't open: restart with Ctrl+Alt+Del → power icon, and hold Shift from the black screen until the account list appears.
  • Last resort, the recovery USB (nothing is erased):
    • Restart the PC (use Restart, not Shut down) and boot from the USB with the boot-menu key (F12, F11 or Esc).
    • At the first Windows Setup screen press Shift+F10. Never click Install now.
    • Run these, using the drive letter that holds Windows: 
      reg load HKLM\OFF C:\Windows\System32\config\SOFTWARE
reg add "HKLM\OFF\Microsoft\Windows NT\CurrentVersion\Winlogon" /v AutoAdminLogon /t REG_SZ /d 0 /f
reg unload HKLM\OFF
    • Remove the USB and restart. The PC stops at the sign-in screen; choose Administrator. Later, Cafe Mode ON turns automatic sign-in back on.
  • Undo everything: as Administrator, Settings → Apps → uninstall “Cafe PC Client”. If the files are gone, run this in PowerShell as administrator: 
    powershell -ExecutionPolicy Bypass -File C:\ProgramData\CafeClient\uninstall_pc.ps1 -RestoreThisPC
  • Logs to bring back:
    • Setup, including the self-check: C:\ProgramData\CafeClient\setup-*.log
    • PC client: C:\Users\Player\AppData\Local\CafeClient\client.log and startup-error.log
    • Server: a screenshot of the server window
  • Note which item failed and what you saw. Fixes mean a new CafeSetup.exe, installed over the old one.
Never run CafeSetup.exe on the server PC: it refuses to run there anyway. A Windows 11 PC with Smart App Control on will block it.
