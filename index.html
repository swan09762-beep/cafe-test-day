If something goes wrong

  • Get to Windows on the test PC: Ctrl+Shift+F12 + staff PIN, or hold Shift while Windows starts. Then sign in with your admin account.
  • Undo everything: Settings → Apps → uninstall “Cafe PC Client”.
  • Logs to bring back:
    • Setup: C:\ProgramData\CafeClient\setup-*.log
    • PC client: C:\Users\Player\AppData\Local\CafeClient\client.log
    • Server: a screenshot of the CafeServer window
  • Note which item failed and what you saw. After a fix, run build.bat again and reinstall.
Never run CafeSetup.exe on the development PC: it refuses to run there anyway.
